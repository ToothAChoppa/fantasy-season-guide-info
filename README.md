# 2026 In-Season Fantasy Guide

A personal, noncommercial fantasy football companion used by one manager for one Yahoo Fantasy Football league. It runs locally on macOS and Windows and is not offered as a service to others.

The companion reads league roster settings, the manager’s roster, available-player information, player status, and matchup context after the manager authorizes read-only Yahoo Fantasy API access. It combines those inputs with independent projections and weekly kicker/defense consensus ranks to show advisory starting lineups and waiver add/drop comparisons. It never changes a Yahoo lineup or submits a transaction.

While API access is unavailable, the same local guide accepts a CSV import. Credentials remain in each machine’s credential manager; league data remains in a local cache. This public page contains no credentials or league data.

This project is not affiliated with or endorsed by Yahoo. [Yahoo Fantasy](https://football.fantasysports.yahoo.com/) is the source of authorized league information when API access is approved.
